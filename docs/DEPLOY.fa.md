# راهنمای استقرار (فارسی)

## پیش‌نیازها
- بانری یا سرور لینوکس/ویندوز/مک. برای اجرای فایل تکی، فقط فایل `pq-server` لازم است.
- پورت پیش‌فرض: `8787` (قابل تغییر با `--port`).

## اجرای آفلاین
```sh
./pq-server --offline --port 8787
```
سپس مرورگر را به `http://localhost:8787` باز کنید. پیکره و کارگاه به‌صورت برون‌خط کار می‌کنند.

## به‌روزرسانی پیکره (یک فایل)
```sh
./pq-server --data ./new-pack.json --port 8787
```
فقط فایل داده جایگزین می‌شود؛ نیازی به بازسازی باینری نیست.

## بررسی چک‌سام
```sh
sha256sum pq-server-linux-x64
```
خروجی را با چک‌سام منتشرشده مقایسه کنید. در ویندوز، فایل امضا نشده ممکن است هشدار SmartScreen/آنتی‌ویروس بدهد؛ پس از بررسی چک‌سام، اجرا را تأیید کنید.

## پشتیبان‌گیری
پوشهٔ داده (پیکره، IndexedDB محلی) را کپی کنید. کارگاه پشتیبان `.pqw` می‌سازد.

## Docker
```sh
docker compose up -d
```
healthcheck روی `/v1/health` تنظیم شده است.

## عیب‌یابی
- پورت اشغال: `--port` را تغییر دهید.
- عدم دسترسی به شبکه: `--offline` را فعال کنید.
- CORS: `--cors https://example.com`.
